# DeepGuard AI — Model Export & Serialization Specification

## 1. Checkpoint Directory Structure

DeepGuard AI decouples model code from weight files and maintains companion configuration files:

```text
backend/
└── artifacts/
    └── models/
        ├── efficientnet_b0/
        │   ├── best_model.pth          # PyTorch weights file (from Colab)
        │   ├── model_config.json       # Metadata & preprocessing config
        │   └── .gitkeep
        └── xception/
            ├── best_model.pth          # PyTorch weights file (from Colab)
            ├── model_config.json       # Metadata & preprocessing config
            └── .gitkeep
```

---

## 2. Checkpoint Structure (`best_model.pth`)

The `.pth` weights file generated by `training/src/utils/export.py` is a serialized dictionary containing:

```python
{
    "epoch": int,                          # Best epoch index (e.g., 12)
    "model_architecture": str,             # "efficientnet_b0" or "xception"
    "state_dict": OrderedDict,             # Model parameters (tensors)
    "optimizer_state_dict": dict,          # AdamW optimizer state
    "best_metrics": {                      # Validation scores at checkpoint time
        "val_loss": float,
        "val_acc": float,
        "val_roc_auc": float,
        "val_f1": float
    },
    "config": dict                         # Copy of deployment configuration
}
```

## 3. Configuration Schema (`model_config.json`)

The companion `model_config.json` is human-readable and read by `ModelManager` upon backend initialization:

```json
{
  "model_name": "efficientnet_b0",
  "display_name": "EfficientNet-B0 Deepfake Detector",
  "architecture": "efficientnet_b0",
  "num_classes": 2,
  "classes": ["REAL", "FAKE"],

    "face_crop_margin": 0.25,

  }

```

---

## 4. Verification Check Before Inference

Upon startup or invocation, `ModelManager` validates:
1. `checkpoint_path.exists() == True`
2. `checkpoint_path.stat().st_size > 1000` (ensures not a dummy empty file)
3. Keys inside `state_dict` match target model layer definitions.
4. If missing, `ModelManager` raises `CheckpointMissingError(model_name, expected_path)` without falling back to fake numbers or simulated random scores.
