# Deep Learning Portfolio

Welcome to my **Deep Learning Portfolio**.

This repository documents my journey of learning Deep Learning and Computer Vision from first principles using **PyTorch**. Every project is built progressively—from implementing my own Convolutional Neural Networks to working with modern pretrained architectures and, eventually, real-time AI surveillance systems.

Rather than treating deep learning as a collection of libraries, my goal is to understand **how models learn, why architectural choices matter, and how AI systems are built for real-world applications**.

# Learning Philosophy

This repository focuses on understanding the complete Deep Learning pipeline rather than simply using pretrained models.

For every project, I aim to understand:

* Data preprocessing
* Model architecture
* Forward propagation
* Loss computation
* Backpropagation
* Optimization
* Validation
* Inference
* Deployment considerations

Each project builds upon the previous one, creating a structured progression from fundamental CNNs to modern AI systems.

# Long-Term Vision

The long-term goal of this repository is to develop practical expertise in modern Computer Vision and Deep Learning by progressively building more advanced projects.

The journey culminates in **GuardianGrid**, an AI-powered smart surveillance platform capable of:
